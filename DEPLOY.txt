eaindrayiscoding.com - deploy steps (GitHub Pages, free hosting)

1. On GitHub, create a new public repository named exactly:  EaindrayMFU26.github.io
2. Upload these three files to it:  index.html   Eaindray_CV.pdf   CNAME
   (The CNAME file contains one line: eaindrayiscoding.com)
3. Within a minute the site is live at https://eaindraymfu26.github.io
4. Buy the domain eaindrayiscoding.com from any registrar, then add these DNS records there:
     A      @      185.199.108.153
     A      @      185.199.109.153
     A      @      185.199.110.153
     A      @      185.199.111.153
     CNAME  www    eaindraymfu26.github.io
5. In the repository: Settings > Pages > Custom domain > enter eaindrayiscoding.com > Save.
   When the DNS check passes (can take up to 24 hours), tick "Enforce HTTPS".
