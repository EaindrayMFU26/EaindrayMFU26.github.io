CareMind, an AI assistant for nurses

CareMind drafts nursing notes from patient records. Every clinical statement is linked to its source record, and nothing reaches the patient's chart until a nurse reviews and approves it. Developed and tested with MFU Medical Center Hospital.

My part
  • Run a self-hosted large language model on university hardware, producing a full handover note in about 12 seconds
  • Built the step that links each statement to its source record, so the AI never writes its own citations
  • Built the Next.js backend and the admin console for setup, system status and audit history, deployed with Docker
  • Set up automated tests and daily quality checks on generated notes
